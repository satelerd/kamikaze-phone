# Archived implementations

Archived applications remain available for research and historical comparison, but are not product release targets. Keep fixes to an archive narrowly scoped and do not add dependencies from an active app to archived code.

Milestone snapshots within an active implementation are represented by immutable Git tags instead of copied directories. See [`../docs/HISTORY.md`](../docs/HISTORY.md).

`web-prototype/` preserves the common original browser baseline. `explorations/` contains complete snapshots of genuinely divergent early pull requests whose interaction ideas would otherwise not exist on the current `main` tree.
