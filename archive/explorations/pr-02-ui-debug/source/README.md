# Kamikaze Phone

Aplicación experimental que mide los sensores del teléfono y ofrece un par de modos de juego para lanzarlo al aire.

## Modos de juego

- **Kamikaze Clásico**: calcula la altura máxima obtenida en un lanzamiento.
- **Flip Frenzy**: cuenta los flips efectuados y otorga puntos en base a los giros y la altura.

Ambos modos muestran datos de depuración para facilitar el testeo. También puedes ir a la sección de **Giroscopio en tiempo real** para visualizar los valores de orientación.

El proyecto está construido con Next.js y TailwindCSS.
